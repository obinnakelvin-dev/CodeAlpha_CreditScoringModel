# Credit Scoring Model

A machine learning project that predicts the likelihood of loan default using borrower and loan information.

## Project Overview

This project was developed as part of the **CodeAlpha Machine Learning Internship**.

The goal is to build a machine learning model that analyzes credit-related information and predicts whether a borrower is likely to default on a loan.

The project uses **Logistic Regression** and compares a standard model with a class-balanced version.

## Dataset

The project uses the **Credit Risk Dataset**, which contains information about borrowers and their loans.

The dataset includes features such as:

* Person age
* Person income
* Home ownership
* Employment length
* Loan intent
* Loan grade
* Loan amount
* Loan interest rate
* Loan percentage of income
* Previous default history
* Credit history length

The target variable is:

* `0` — No default
* `1` — Default

## Machine Learning Process

The project follows these steps:

1. Load the dataset
2. Inspect the data
3. Handle missing values
4. Remove duplicate records
5. Separate features and target
6. Encode categorical variables
7. Split the dataset into training and testing sets

9. Train Logistic Regression models
10. Evaluate model performance
11. Compare baseline and balanced models
12. Save the trained model
13. Use the saved model to make new predictions

## Models

### Model 1 — Baseline Logistic Regression

The baseline model uses standard Logistic Regression without class weighting.

### Model 2 — Balanced Logistic Regression

The second model uses:

`class_weight="balanced"`

This gives additional importance to the default class and helps the model identify more potential default cases.

## Model Results

| Metric    | Baseline Model | Balanced Model |
| --------- | -------------: | -------------: |
| Accuracy  |         86.91% |         81.46% |
| Precision |         77.33% |         55.48% |
| Recall    |         56.77% |         77.08% |
| F1-Score  |         65.47% |         64.52% |
| ROC-AUC   |         86.79% |         86.96% |

The two models demonstrate a trade-off between precision, recall, and overall accuracy.

The balanced model detected more of the actual default cases, while the baseline model achieved higher accuracy and precision.

## Prediction System

The project includes `predict.py`, which allows a user to enter borrower information and receive a predicted credit-risk result.

Example:

```text
Probability of default: 31.15%

Prediction: LOWER DEFAULT RISK
```

The prediction is generated by the trained machine learning model.
